Move funds out

This page sends money from your Session Firewall account to one of your trusted destinations. It works even when trading is paused or the hourly spending limit is used up. It is a single file: it talks only to the network addresses you type below, and to nothing else.

          Set up a recovery key for this page
          
    
            A passkey only works on the website it was made for. If you want to be able to move funds
            out even when the main website is gone, make a second passkey here, on the address where
            you keep this page (for example http://localhost:8000), and add it to your
            account from the main app. Adding a key waits 24 hours, like every other loosening change,
            and you can cancel it during that time.
